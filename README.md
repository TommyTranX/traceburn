# traceburn (working name, prerelease)

A local-first tracer and efficiency profiler for AI agents. Records every LLM
and tool call into one local SQLite file, then shows you where the time and
money went: cost and latency flamegraphs, deterministic replay, run diffs, and
waste detection.

This is a prerelease work in progress. The full README lands with v0.1.0.

No telemetry. This tool makes no network calls of its own.
